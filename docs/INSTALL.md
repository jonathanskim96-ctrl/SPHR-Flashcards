# Install SPHR Flashcards on Michelle's iPhone

Takes about 3 minutes. You need the iPhone, Wi-Fi or data, and the email and password
Jonathan set up.

## 1. Add the app to the Home Screen

1. Open **Safari** (the blue compass icon). It must be Safari, not Chrome or another app.
2. Type this address and tap **Go**:
   `jonathanskim96-ctrl.github.io/SPHR-Flashcards`
3. Tap the **Share** button (a square with an arrow pointing up). Depending on the iPhone
   version it's at the bottom of the screen, or behind the **⋯** button next to the address.
4. Scroll down the list and tap **Add to Home Screen**. (If you don't see it, tap
   **More** / **Edit Actions** at the bottom of the list and add it.)
5. If you see an **Open as Web App** switch, make sure it is **on**.
6. Tap **Add** (top right).
7. Go to the Home Screen and find the new **SPHR** icon.

## 2. Open it from the icon and sign in

1. Tap the **SPHR** icon. Always use this icon from now on, not Safari. Safari and the
   icon are kept separate, and reminders only work from the icon.
2. Enter the email and password and tap **Sign in**. You'll stay signed in.

## 3. Turn on the daily reminder

The first time the app opens from the icon, Home shows **"Turn on daily reminder (3:00 PM)?"**.
Tap **Turn on** and skip to step 3. (If you tapped **Not now**, use Settings as below.)

1. In the app, tap **Settings**.
2. Tap **Remind me every day** to turn it on. (If you see "Add this app to your Home Screen first"
   instead, you opened it in Safari, not from the SPHR icon. Open the icon and try again.)
3. iPhone asks **"SPHR" Would Like to Send You Notifications**. Tap **Allow**.
4. The reminder time is **3:00 PM**. To change it, tap the time and pick another (it moves
   in 15-minute steps).

You'll get "You should practice some questions" once a day at that time.

**If you tapped "Don't Allow" by mistake:** open the iPhone **Settings** app →
**Notifications** → scroll to **SPHR** → turn on **Allow Notifications**. Then go back to
the app → Settings → turn the reminder on. (If it already shows on, going back to the app is
enough.)

**If reminders don't arrive:** check that a **Focus** mode (Do Not Disturb, Sleep, Work) isn't
silencing it (iPhone Settings → **Focus**), and that the app was opened from the icon at
least once in the last few days. Opening the app refreshes the reminder connection.

## 4. Good habits

- **Back up weekly:** app **Settings** → **Export progress** → **Save to Files** → choose
  **iCloud Drive** → **Save**.
- **Don't delete the SPHR icon** without first checking that app Settings says **"All
  answers backed up"**. Deleting the icon deletes anything not yet backed up.
- When the app shows **"New version: Reload"**, tap it.
- Studying works without internet; answers back up the next time you're online.

## 5. First-day checklist (Jonathan, on her phone)

Tick each one. Tell the build session about anything that fails.
- [ ] The app opens from the icon full-screen (no Safari address bar).
- [ ] Sign-in works.
- [ ] A lesson shows all six question kinds over time; drag-to-reorder works with a finger,
      and the ▲/▼ buttons work too.
- [ ] Matching works by tapping a prompt, then an option, and by holding an option for a
      moment and dragging it onto a prompt. Scrolling the screen with a finger on an option
      still scrolls.
- [ ] Typing in a fill-in answer doesn't auto-capitalize or autocorrect.
- [ ] Airplane mode on → the app still opens and a lesson works → Airplane mode off →
      Settings says "All answers backed up".
- [ ] Set the reminder 15–30 minutes ahead; it arrives (lock the phone and wait). Then set
      it back to 3:00 PM.
- [ ] Export progress opens the share sheet; **Save to Files** saves a file you can see in
      the Files app, and Settings then says "Last export: today". (Cancelling the sheet says
      "Export cancelled" and does not count as an export.)
